# How to Use AINS6001

This page is the starting point for **AINS6001 Foundations of Artificial Intelligence**. The course is not a collection of unrelated files: each module follows the same learning sequence.

## Student Path: One Module at a Time

1. **Orient:** open the module overview and read its essential question, scenario, outcomes, and required artifact.
2. **Learn:** read the book-prose chapter. Use the study questions to check comprehension.
3. **See the explanation:** open the slide deck. The matching narration provides the spoken teaching script when the course is asynchronous.
4. **Practice:** launch the lab in Google Colab, run all cells, change one named variable, and record what changed.
5. **Demonstrate:** complete the assignment notebook and compare your work with the rubric before submitting.

Do not begin by opening every file in the repository. Start with the overview for the current module and follow the links in order.

## What the Course Terms Mean

- **Jupyter Book:** the web textbook you are reading. It combines prose, notebooks, assignments, and teaching materials into one navigable site.
- **Course repository / GitHub hub:** the public cohort repository at [https://github.com/Aurnova/ains6001-course](https://github.com/Aurnova/ains6001-course) contains the student-facing source files for cloning and notebook work.
- **Notebook:** an interactive document containing explanations, executable code, output, and response areas.
- **RISE-ready slides:** slide notebooks include presentation metadata. Anyone can read the rendered slide page in a browser; facilitators can open the notebook in JupyterLab and use RISE for full-screen presenter mode.
- **Colab:** Google's browser notebook environment. The provided labs work with the free tier; a paid Colab Pro subscription is not required.
- **Codespaces:** a browser-based copy of the complete repository for activities that need several files, a terminal, or Git.
