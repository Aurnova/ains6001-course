# AIN6001 Lab and Assignment Workspaces

## Start in Google Colab

Use the module links below to open the course notebooks. Sign in with your
Google account, then choose **File > Save a copy in Drive** before editing.
Choose **Runtime > Run all** to run the starter code. You do not need to connect
GitHub to Colab or authorize access to a private repository.

The lab is guided practice. The assignment contains the assessed tasks; follow
the module rubric and your instructor's submission instructions in Populi.
Colab does not submit your work to Populi automatically. Download your completed
notebook with **File > Download > Download .ipynb**, or share your saved Drive
copy with your instructor when a link submission is requested. Keep your work
private; give your instructor access explicitly rather than making it public.

## GitHub Codespaces

Use GitHub when your instructor asks for repository-based work. Sign in to
Classroom 50 with your GitHub account, accept the Aurnova organization invitation
and course enrollment when offered, then accept the module assignment. In your
assignment repository choose **Code > Codespaces > Create codespace**. Commit
and push your changes; opening a Codespace alone does not submit an assignment.

For demonstrations and browsing, the [public course repository](https://github.com/Aurnova/ains6001-course)
and [course Codespace launcher](https://codespaces.new/Aurnova/ains6001-course)
are also available. A Codespace on the shared course repository is your personal
working environment, not a private assignment repository or a Populi submission.

## Instructor Access

Instructors can use every Colab link above without a student enrollment in
Classroom 50. For GitHub submissions, accept your course-staff invitation while
signed in as the invited account, then open the
[AIN6001 staff dashboard](https://classroom50.org/Aurnova/ain6001).
The assignment accept links are the student entry point, not the staff dashboard.
Student enrollment and GitHub invitations must be accepted before private
assignment access works; no activation is needed for the public Colab notebooks.

If an older PDF opens Colab against `CastaliaInstitute`, return to this guide
and use the public Aurnova link for the same module.
